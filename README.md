# Amazon Sales Dashboard

## About the Project

I made this project to analyze Amazon sales data using Excel.
The dashboard helps to understand sales and product performance
in a simple way.

## Tools Used

- Excel
- Pivot Table
- Pivot Chart
- Slicer
- Excel Formulas

## What I Analyzed

- Total Revenue
- Total Orders
- Total Quantity
- Average Rating
- Sales by Product
- Sales by Category
- Sales by City
- Sales by Branch
- Payment Method
- Sales Performance

## Dashboard

The dashboard contains different charts, KPI cards and filters.
Slicers can be used to check the data based on different categories.

## Purpose

The main purpose of this project was to practice Excel data
analysis and create an interactive sales dashboard.
